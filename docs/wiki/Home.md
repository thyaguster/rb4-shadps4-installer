# RB4 shadPS4 Installer Wiki

RB4 shadPS4 Installer sets up and maintains Rock Band 4, RB4 Deluxe, game updates, DLC, and custom songs for shadPS4 on Windows.

## Start here

- **New setup:** [Getting Started](Getting-Started)
- **Already installed:** [Managing an Existing Installation](Managing-an-Existing-Installation)
- **What each folder means:** [Emulator and Paths](Emulator-and-Paths)
- **Something went wrong:** [Troubleshooting](Troubleshooting)
- **Original projects and contributors:** [Credits](Credits)

> [!IMPORTANT]
> This project does not provide Rock Band 4, updates, DLC, firmware, keys, or other copyrighted game content. Use lawful dumps made from software you own.
