# Managing an Existing Installation

## Duplicate-safe content imports

The Content queue compares extracted folders and recognizable PKG filenames with the installed add-on library. Items already present are marked **INSTALLED** and skipped by default. If a PKG's identity is only available after extraction, the installer performs the same check before copying files.

Enable **Reinstall items already detected as installed** only when intentionally repairing or replacing content. Existing backup and rollback behavior still applies.

When the selected shadPS4 paths contain Rock Band 4, the installer detects the title ID, installed game version, RB4 Deluxe status, and add-on count. Base-game fields are hidden because they are no longer needed.

## Update the game

Choose **Install game update**, then select or drag the update PKG or extracted update folder. The update must match the detected region.

## Install or repair RB4 Deluxe

Choose **Repair RB4 Deluxe** or **Update or reinstall Deluxe**. You can select a ZIP or extracted folder, or download the current official RB4 Deluxe package offered by the installer.

## Add DLC or custom songs

Content imports unlock after RB4DX is detected. Custom songs do not work with standard RB4, and a mixed PKG folder cannot be reliably separated into official DLC and customs from filenames alone. If only standard RB4 is detected, choose **Install RB4 Deluxe** first. Game updates remain available independently.

Choose **Content** in the header. The content manager combines the searchable installed-content library with these source options:

- **Add PKGs:** select one or more individual package files.
- **Add PKG folder:** select a collection folder; the installer recursively finds and queues every `.pkg` inside it.
- **Add extracted folder:** select one already-unpacked add-on folder.

Every item must match the installed game's region. The manager can process multiple queued items in one run through **Review & install queued content**.

Queued sources show the filename while preserving the complete path in a tooltip. The installed-content list reads each package's metadata and displays its title, content ID, version, type, and folder location.

The manager recognizes the standard `Custom:` and `Custom Pack` titles generated by LibForge. All other packages are labeled **DLC / unclassified**. The `UP8802`/`EP8802` publisher prefix is not sufficient proof: it is used by official Rock Band 4 content as well as community tooling, so ambiguous metadata is never presented as a confident classification.

Choose **Audit library** for a read-only validation pass. It reports missing, unreadable, or wrong-region `param.sfo` metadata, duplicate content IDs, unexpected package categories, empty folders, and linked directories that were deliberately skipped. The results window changes nothing and offers **Copy report** for troubleshooting.

Choose **Export catalog** to save a UTF-8 CSV inventory of the complete installed library. The export includes the game title ID, content name and ID, type, enabled/disabled state, version, recursive size in bytes, and folder. It always exports every detected item even when the on-screen list is filtered, and it safely quotes spreadsheet fields.

## Content profiles

Select installed items and choose **Disable selected** to stop shadPS4 loading them without deleting anything. Disabled folders remain beside the active add-on library in the installer's dedicated disabled-content area and can be restored with **Enable selected**.

Enter a profile name and choose **Save current** to remember the exact enabled set. Applying a named profile enables its saved folders and disables the others transactionally; if any move fails, completed moves are reversed. Profiles store folder identities only—they do not duplicate content. Reinstalling a disabled item repairs it in place and keeps it disabled.

To uninstall content, select one or more installed items and choose **Move selected to Recycle Bin**. The manager verifies that every selected folder is a direct child of the detected game's configured add-on directory, asks for confirmation, and uses the Windows Recycle Bin so accidental removals can be restored. It never removes the game folder or entire add-on root.

## Backups and rollback

With backups enabled, overwritten files are preserved before installation. If an operation fails after changes begin, the installer attempts to restore the previous state and records details in the installation log.

Before every destination write, the installer durably records the file and its prior state. After a process crash or power loss, the next launch offers **Resume safely**, **Roll back**, and **Clean staging**. Resume first restores the complete checkpoint and then retries the saved request from its original sources; it never continues blindly from a partially copied file.

New recovery backups store the original size and SHA-256 checksum of every protected file. Open **Settings → Recovery backups** and choose **Verify integrity** to check a selected backup without changing the installation. Restore performs the same complete check before it modifies any destination, so a missing, truncated, or altered backup file stops the operation safely.

Backups created by versions before 0.8.19 remain available and receive structural checks for required files and safe paths. They are labeled **legacy backup** because their older manifests do not contain cryptographic checksums.

The recovery manager reports the stored size of each backup and the collection's total disk usage. **Delete older** permanently removes only superseded backups and always keeps the newest recovery point independently for each supported game region. A confirmation shows the number of backups and approximate space to reclaim before anything is deleted.

Close shadPS4 before changing game files, restoring a backup, or updating a managed emulator build.
