# Getting Started

## 1. Download the installer

Open [Releases](https://github.com/thyaguster/rb4-shadps4-installer/releases/latest) and choose one package:

- **Setup:** installs the app normally and can create shortcuts.
- **Portable:** extract the ZIP and run the versioned portable executable.

## 2. Choose shadPS4

On first launch, either select an existing shadPS4 folder or download an emulator build:

- **LlysiX RB4 build (recommended):** the RB4-focused build presented first by the installer.
- **Latest official shadPS4:** the current official Windows release.

Managed downloads are placed in the installer's Local AppData folders. An existing emulator can remain wherever it is already installed.

Managed emulator, RB4DX, PKG-extractor, and application-update downloads retry brief network failures automatically. When the server supports HTTP ranges, retries continue from retained partial bytes; progress text shows when a transfer is retrying or resuming.

## 3. Confirm the paths

Review the shadPS4 application folder, user folder, and game library. See [Emulator and Paths](Emulator-and-Paths) for details.

## 4. Add your game files

Select or drag your own base-game PKG or extracted folder into the matching field. Add the update when available, then choose Standard RB4 or RB4 Deluxe.

PKGs are unpacked with the supported package extractor. Extracted folders can be installed directly.

## 5. Review and install

Check the destination, sources, disk-space estimate, and warnings on the Review page. Keep backups enabled unless you have a specific reason not to.

After installation, restart shadPS4 so it can rescan the game and content.
