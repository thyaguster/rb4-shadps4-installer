# RB4 shadPS4 Installer v0.8.13

## What's new

- Combines installed content and new content imports into one Content manager
- Queues PKGs, recursively scanned PKG folders, and extracted add-on folders from the manager
- Adds a dedicated review-and-install action for queued content
- Supports multi-select removal of installed DLC and custom songs
- Sends removed content to the Windows Recycle Bin for recovery
- Verifies every removal target is a direct child of the configured RB4 add-on folder
- Keeps game updates in the main installer workflow

The installer does not provide copyrighted game content. Use lawful dumps from software you own.
