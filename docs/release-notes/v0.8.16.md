# RB4 shadPS4 Installer v0.8.16

This release adds duplicate detection and safer reinstall controls to the Content manager.

## Added

- Queued extracted folders are identified from `param.sfo` metadata.
- Recognizable PKG filenames are compared with installed content IDs before review.
- Queue items clearly show **READY**, **PKG**, or **INSTALLED** state.
- Already-installed items are skipped by default and counted in the review/completion summaries.
- A deliberate reinstall option allows repair or replacement when the user explicitly chooses it.
- PKGs whose identity is only known after extraction receive a second duplicate check before any installed files are changed.

Existing backup, rollback, and region-validation behavior remains in place.
