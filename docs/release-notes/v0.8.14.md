# RB4 shadPS4 Installer v0.8.14

This release adds a read-only **Setup health** page that checks the complete Rock Band 4 environment before troubleshooting becomes guesswork.

## Added

- Detects the selected shadPS4 executable and whether it is the tested LlysiX RB4 build.
- Verifies that the managed build is using its matching portable user profile.
- Checks the installed RB4 region and version, RB4DX files, installed content, firmware modules, system fonts, add-on path, and free disk space.
- Reads the latest shadPS4 log to identify the branch/revision, confirm the RB4DX plugin started, and flag device-loss or fatal renderer errors.
- Shows clear passed, warning, and error results with suggested next steps.
- Can copy a support-friendly text report or open the latest emulator log.

The check does not change files or settings.
