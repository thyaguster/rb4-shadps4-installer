# RB4 shadPS4 Installer v0.8.19

This release makes retained recovery backups verifiable before they are trusted.

## Added

- New backups record the original size and SHA-256 checksum of every protected file.
- **Verify integrity** checks a selected backup without changing the game or emulator installation.
- The backup list identifies SHA-256-protected and legacy backups.

## Safer restores

- Every restore now verifies all retained files before changing any destination.
- Missing, truncated, modified, or path-escaping backup files stop the restore safely.
- Restore progress clearly separates verification from file restoration.
- Backups created before v0.8.19 remain usable after structural validation and are clearly labeled as legacy backups.
