# RB4 shadPS4 Installer v0.8.21

This release adds a portable inventory export to the installed-content manager.

## Added

- **Export catalog** saves the complete detected DLC/custom-song library as a UTF-8 CSV file.
- Every row includes the game title ID, content name and ID, type, version, recursive size in bytes, and folder.
- Catalog exports include all installed items even when the visible list has a search filter.
- File sizes are calculated only during export, keeping normal content-manager loading fast.

## Export safety

- CSV fields are quoted correctly and spreadsheet-formula-like values are neutralized.
- Output is written to a temporary file and moved into place only after a successful complete export.
- Directory junctions and symbolic links are not followed while calculating sizes.
