# RB4 shadPS4 Installer v0.8.9

## What's new

- Gives the installer-managed LlysiX RB4 build its own portable `user` profile
- Keeps existing shadPS4 installations and AppData profiles untouched
- Migrates configuration, saves, keys, input profiles, sysmodules, and RB4DX data by copying them safely
- Installs RB4DX under `user\data\GoldHEN` for the LlysiX `rb4dx` branch
- Preserves the title-specific Deluxe layout for standard shadPS4 profiles
- Detects Deluxe in either supported layout
- Writes the managed game-library and DLC paths into the isolated emulator configuration
- Carries the isolated profile into staged LlysiX emulator updates before swapping versions
- Prevents hidden DLC queues from running during a Deluxe-only installation

The installer does not provide copyrighted game content. Use lawful dumps from software you own.
