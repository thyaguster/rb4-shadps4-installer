# RB4 shadPS4 Installer v0.8.24

This release connects the installed-content audit to the main Setup health and support workflow.

## Added

- Setup health automatically audits installed DLC/custom-song metadata after detecting Rock Band 4.
- Content errors and warnings appear as a concise health result with the first relevant findings.
- Health recommendations link the user back to **Content → Audit library** for the complete report.
- Redacted support ZIPs now include the content-audit summary through `health-report.txt` without including any game or add-on files.

## Corrected

- A missing per-game add-on folder is now informational when no DLC or custom songs are installed; it is not treated as a broken content library.
