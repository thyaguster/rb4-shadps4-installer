# RB4 shadPS4 Installer v0.8.26

This release makes long Setup health scans cancellable.

## Added

- A visible **Cancel** action while Setup health is scanning.
- Cooperative cancellation while enumerating installed content, system fonts, and the shadPS4 launch log.

## Improved

- Opening Settings, Credits, Content, or returning to the installer stops an active health scan automatically.
- Cancelling a rerun restores the previous completed report instead of leaving an empty page.
- Cancellation returns every health control to its normal state and does not display a failure warning.
