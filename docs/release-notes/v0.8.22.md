# RB4 shadPS4 Installer v0.8.22

This release corrects how the content manager classifies installed custom songs and DLC.

## Fixed

- Recognizes both single-song `Custom:` titles and multi-song `Custom Pack` titles generated by LibForge.
- Uses **Custom song / pack** for recognized community content.
- Uses **DLC / unclassified** when package metadata does not reliably identify the source.
- Updates the installed-content summary and CSV catalog with the corrected classification.

The installer deliberately does not classify content from the `UP8802`/`EP8802` publisher prefix alone. Official Rock Band 4 content uses those identifiers too, so treating the prefix as a custom-song marker would produce incorrect results.
