# RB4 shadPS4 Installer v0.8.34

This release adds detailed source compatibility reports and selectable emulator releases.

## Compatibility reports

- Review region, content type, content ID, duplicate status, RB4DX requirement, confidence, and findings for every selected source.
- Extracted folders use verified `param.sfo` metadata.
- Encrypted PKGs use clearly labeled filename evidence and remain marked for verification after extraction.
- Missing sources and verified region mismatches are shown as blocked.

## Emulator release selector

- Load recent LlysiX RB4 and official shadPS4 Windows releases from GitHub.
- Choose **Latest automatically** or pin an exact release tag per channel.
- Pinned selections are remembered across launches.
- Release rows show publication date and SHA-256 availability; unverified LlysiX RB4 assets are excluded.
- Selected builds retain the existing staged installation, portable-profile migration, and one-click rollback behavior.

## Validation

- Added deterministic tests for release ordering, Qt asset selection, digest enforcement, duplicate inference, confidence labeling, and verified wrong-region blocking.
