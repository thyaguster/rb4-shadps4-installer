# RB4 shadPS4 Installer v0.8.8

![RB4 shadPS4 Installer](https://raw.githubusercontent.com/thyaguster/rb4-shadps4-installer/main/docs/screenshots/installer.png)

## What's new

- Added **Add PKG folder** for large DLC and custom-song collections
- Recursively scans the selected folder and queues every `.pkg`, including uppercase `.PKG` files
- Renamed **Add folder** to **Add extracted folder** so unpacked content is unambiguous
- Moved the automatically detected DLC installation destination into Settings
- Clarified the source-folder picker and destination-folder labels
- Reports how many packages were found and how many new items were queued

The installer does not provide copyrighted game content. Use lawful dumps from software you own.
