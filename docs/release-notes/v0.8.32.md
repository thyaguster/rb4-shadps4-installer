# RB4 shadPS4 Installer v0.8.32

This release adds one-click rollback for installer-managed shadPS4 updates.

## Added

- Settings shows the current and previous managed emulator versions.
- **Restore previous build** supports both the recommended LlysiX RB4 channel and the official shadPS4 channel.
- Restoring swaps the builds, retaining the replaced version so the rollback can be undone.

## Safety

- Official emulator updates now install through a verified staging folder instead of overwriting the active build in place.
- LlysiX rollbacks preserve the newest portable user profile, including settings, saves, firmware modules, and RB4DX data.
- Rollback is restricted to the installer's two managed emulator folders; custom installations are never targeted.
- A deterministic smoke test covers update preservation, rollback, undo, profile continuity, and custom-folder exclusion.
