# RB4 shadPS4 Installer v0.8.7

![RB4 shadPS4 Installer](https://raw.githubusercontent.com/thyaguster/rb4-shadps4-installer/main/docs/screenshots/installer.png)

## What's new

- Added automatic and manual application update checks through GitHub Releases
- Added a branded confirmation window with release notes before downloading
- Added a Settings option to turn automatic update checks off
- Added SHA-256 verification using each release's `SHA256SUMS.txt`
- Added Setup-edition updating through the verified Windows installer
- Added Portable self-updating through a hidden, one-time handoff helper
- Preserved all game, emulator, content, and saved-path data during app updates

## Portable update behavior

The helper runs only after an update is accepted. It waits for the old executable to close, places and starts the new version, removes the old executable, and then removes itself.

The installer does not provide copyrighted game content. Use lawful dumps from software you own.
