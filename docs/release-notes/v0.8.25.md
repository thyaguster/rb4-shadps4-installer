# RB4 shadPS4 Installer v0.8.25

This release keeps Setup health responsive while it inspects large RB4 content libraries and logs.

## Improved

- Setup health now runs its filesystem and content audit work in the background instead of blocking the installer window.
- The health action shows **Checking…** and is disabled while a scan is active.
- Repeated requests share the active scan instead of starting duplicate filesystem work.
- **Copy report** and **Export support ZIP** wait for the current scan, preventing an older report from being copied or exported mid-scan.
- Scan failures restore the controls and show a useful error instead of leaving the health page stuck.
