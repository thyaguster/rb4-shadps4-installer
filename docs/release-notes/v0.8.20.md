# RB4 shadPS4 Installer v0.8.20

This release makes retained recovery-backup storage visible and easier to manage safely.

## Added

- Each backup now shows how much disk space its protected files use.
- The recovery manager summarizes the total number and size of retained backups.
- **Delete older** cleans up superseded recovery points while always retaining the newest backup for each game region.
- Cleanup confirmation shows exactly how many backups will be deleted and the approximate space reclaimed.

Individual verification, restoration, folder access, and deletion remain available. Cleanup never changes the current game installation.
