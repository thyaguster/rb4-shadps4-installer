# RB4 shadPS4 Installer v0.8.33

This release adds durable interrupted-install recovery and non-destructive content profiles.

## Interrupted-install recovery

- Every destination file is journaled before it is changed.
- After a process crash or power loss, the next launch offers **Resume safely**, **Roll back**, and **Clean staging**.
- Resume restores the complete pre-install checkpoint before retrying the saved request; it never continues from a partially copied file.
- Staging cleanup reclaims extracted temporary files without discarding rollback data.

## Content profiles

- Enable or disable selected DLC/custom-song folders without deleting or duplicating them.
- Save the current enabled set as a named profile and switch profiles transactionally.
- Failed profile switches reverse completed moves automatically.
- Disabled items remain visible, searchable, exportable, and repairable while preserving their disabled state.

## Validation

- Added deterministic tests for crash-journal discovery, staging cleanup, file rollback, profile save/apply/delete, and enabled-state switching.
