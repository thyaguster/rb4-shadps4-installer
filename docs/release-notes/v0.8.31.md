# RB4 shadPS4 Installer v0.8.31

This release lets you safely cancel managed downloads from the installer footer.

## Added

- The existing footer changes to **Cancel download** while an emulator, RB4DX, PKG-extractor, or application update is downloading.
- Competing download and installation actions remain disabled until cancellation finishes.
- Controls and neutral status text are restored after cancellation.

## Download behavior

- Cancelled application updates keep their partial data so the same update can resume later.
- Temporary emulator, RB4DX, and PKG-extractor downloads are cleaned up after cancellation.
- A deterministic regression test verifies that user cancellation stops immediately, does not trigger an automatic retry, and retains resumable partial data.
