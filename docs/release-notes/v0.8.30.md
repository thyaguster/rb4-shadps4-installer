# RB4 shadPS4 Installer v0.8.30

This release makes managed downloads resilient to brief network interruptions.

## Added

- Emulator, RB4DX, PKG-extractor, and application-update downloads retry up to three times.
- Retry requests use HTTP byte ranges to continue from retained partial bytes when supported by the server.
- Progress text distinguishes normal downloads, interrupted retries, and resumed transfers.

## Safety

- Completed downloads are moved from `.part` files into place atomically.
- Resume responses are validated against the requested byte offset before bytes are appended.
- Known SHA-256 checks for shadPS4, the PKG extractor, and installer updates still run after the transfer completes.
- A deterministic CI test simulates a dropped connection and verifies the resumed file byte-for-byte.
