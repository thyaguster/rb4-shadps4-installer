# RB4 shadPS4 Installer v0.8.12

## What's new

- Adds local import for decrypted PS4 `.sprx` modules dumped by the user
- Validates ELF module files and skips invalid or encrypted files
- Shows recognized, additional, and missing firmware-module status
- Confirms before replacing same-named modules
- Imports into the active managed or user-selected `sys_modules` folder
- Links directly to the official shadPS4 dumping guide
- Continues preserving imported modules across managed emulator updates

Sony firmware is not included or downloaded. Users must dump modules from a PlayStation 4 they own.
