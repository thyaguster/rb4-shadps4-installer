# RB4 shadPS4 Installer v0.8.17

This release adds local import and validation for dumped PS4 system fonts.

## Added

- Shows installed file counts for both `fonts\font` and `fonts\font2` in Settings.
- Imports either folder individually or discovers both below a selected parent dump folder.
- Supports nested `/preinst/common/font` and `/system/common/font2`-style dump layouts.
- Confirms the detected folders, file counts, and destination before copying.
- Safely merges files into the active shadPS4 profile, replacing only same-named relative paths.
- Links directly to the official shadPS4 font-dumping instructions.
- Setup health now directs missing-font warnings to the new importer.

The installer does not download or provide Sony firmware or font files. Users must supply dumps made from a PlayStation 4 they own.
