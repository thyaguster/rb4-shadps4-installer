# RB4 shadPS4 Installer v0.8.28

This release adds recoverable diagnostics for unexpected installer failures.

## Added

- A themed crash window replaces silent exits after unexpected UI errors.
- Crash reports record the installer/runtime environment and complete exception details locally.
- The crash window can open the saved report folder or copy details for troubleshooting.
- The latest crash report is included in a support ZIP after the normal path and personal-data redaction.

## Safety and maintenance

- Crash reports are limited to the newest ten files so they cannot accumulate indefinitely.
- Reports never contain game files, PKGs, firmware, keys, saves, or add-on contents.
- A new CI smoke test verifies report creation, UTF-8 output, diagnostic contents, and retention.
