## RB4 shadPS4 Installer v0.8.3

A Windows installer for setting up and maintaining Rock Band 4 with shadPS4.

![RB4 shadPS4 Installer](https://raw.githubusercontent.com/thyaguster/rb4-shadps4-installer/main/docs/screenshots/installer.png)

### Download

- **Setup** — recommended for most users
- **Portable ZIP** — extract and run without installing
- **SHA256SUMS.txt** — checksums for both downloads

### Highlights

- Base game and update installation from your own PKGs or extracted folders
- RB4 Deluxe download, installation, repair, and detection
- DLC and custom-song management
- Recommended LlysiX RB4 build plus the latest official shadPS4 channel
- Existing-install detection, backups, rollback, logs, and desktop shortcuts
- New application and tray-ready icon

> This project does not include Rock Band 4, DLC, firmware, keys, or other copyrighted game content. Use lawful dumps made from software you own.

See the [README](https://github.com/thyaguster/rb4-shadps4-installer#readme) for setup instructions, screenshots, credits, and source-build information.
