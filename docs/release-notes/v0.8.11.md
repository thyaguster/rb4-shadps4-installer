# RB4 shadPS4 Installer v0.8.11

## What's new

- Adds a searchable Installed Content page for DLC and custom songs
- Shows package titles, content IDs, versions, and folder locations from installed metadata
- Displays queued PKGs by filename while keeping the full path available on hover
- Locks the mixed DLC/custom importer until RB4DX is detected
- Keeps game-update installation available for standard RB4
- Provides a direct **Install RB4 Deluxe** action when content imports are locked

The installer does not provide copyrighted game content. Use lawful dumps from software you own.
