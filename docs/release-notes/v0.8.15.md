# RB4 shadPS4 Installer v0.8.15

This release adds a privacy-aware support bundle exporter to **Setup health**.

## Added

- Exports the current health report, latest shadPS4 log, latest installer log, and basic runtime details as a ZIP.
- Redacts configured local paths, the Windows user name, email addresses, and IPv4 addresses.
- Limits large logs to their newest 4 MiB so support archives remain manageable.
- Explains exactly what is included and asks for confirmation before creating the archive.
- Reminds the user to review every text file before sharing it.

The bundle deliberately excludes configuration files, account data, keys, saves, firmware modules, game files, PKGs, DLC/custom-song files, and backup contents.
