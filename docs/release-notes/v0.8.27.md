# RB4 shadPS4 Installer v0.8.27

This release makes Setup health progress visible and hardens the repository screenshot workflow.

## Improved

- Setup health now names the stage it is checking: emulator/profile, game and Deluxe, installed content, firmware/fonts, or storage/logs.
- Installed-content health audits show the completed and total folder count while scanning.
- Progress remains compatible with the cancellable background scan introduced in v0.8.26.

## Project tooling

- The screenshot helper is now included in the source repository.
- Screenshots render directly from the app window instead of copying desktop coordinates, preventing DPI-offset captures and unrelated desktop content from appearing in project images.
- The first-run screenshot has been regenerated at the correct full-window size.
