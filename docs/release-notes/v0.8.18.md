# RB4 shadPS4 Installer v0.8.18

This release makes firmware, font, and add-on handling follow shadPS4's active configured paths.

## Fixed

- Resolves `sys_modules_dir`, `font_dir`, and `addon_install_dir` from `config.json`.
- Supports both absolute paths and paths relative to the selected shadPS4 user folder.
- Module/font status, imports, folder buttons, and Setup health now inspect the directories the emulator actually uses.
- Settings identifies non-default module and font locations as custom paths and exposes their full resolved locations.
- Installer-managed LlysiX profiles are aligned to their isolated portable module, font, and add-on directories.
- Configuration updates preserve unrelated sections and unknown keys.

Existing custom paths in user-selected standard shadPS4 profiles are respected and are not replaced.
