# RB4 shadPS4 Installer v0.8.23

This release adds a read-only health audit for installed DLC and custom-song libraries.

## Added

- **Audit library** scans every detected installed-content folder without changing it.
- Reports missing or unreadable `param.sfo` metadata.
- Detects content targeting the wrong RB4 region.
- Detects duplicate content IDs that may conflict during loading.
- Warns about unexpected package categories, empty folders, and linked directories that were skipped.
- Shows a styled results window with error/warning totals and a copyable plain-text report.

The audit never deletes, moves, repairs, or rewrites content. It is intended as the first troubleshooting step when installed songs or DLC do not appear in shadPS4.
