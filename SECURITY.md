# Security policy

## Reporting a vulnerability

Please do not publish exploitable security issues in a public issue before a fix is available. Use GitHub's private vulnerability reporting feature when it is enabled for the repository, or contact the repository owner privately through the contact method listed on their GitHub profile.

Include the affected version, reproduction steps, expected impact, and any suggested mitigation. Do not include real game files, account credentials, keys, or other sensitive user data.

## Download security

The installer narrows automated downloads to expected release assets and verifies publisher-provided SHA-256 digests where supported. A digest verifies the downloaded file against GitHub's release metadata; it does not independently audit or endorse the downloaded software.
